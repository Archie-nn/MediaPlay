# 簡易音訊播放器(MediaPlay)1133334楊恩奇

這是一個輕量級的桌面應用程式，專門用於播放、循環播放及停止 WAV 格式的音訊檔案。透過此專案，可以學習如何使用 .NET 內建的 System.Media.SoundPlayer 類別進行多媒體操作。

## 主要功能
- 檔案瀏覽器：整合 OpenFileDialog，自動過濾並選取 .wav 檔案。

- 單次播放：載入指定路徑之音訊並執行單次播放。

- 循環播放 (Looping)：支援音效無間斷循環，適合背景音樂播放。

- 停止播放：透過檔案串流 (FileStream) 機制安全停止當前音效。

- 關閉防護：內建 FormClosing 確認視窗，防止意外關閉程式。

## 技術實作細節
本程式展示了 SoundPlayer 類別三種不同的初始化與操作方式：

1. 指定路徑播放
使用 SoundLocation 屬性指定檔案位置，並呼叫 Load() 確保資料加載後播放。

2. 循環播放
直接在建構子傳入路徑，並使用 PlayLooping() 開啟循環模式。

3. 檔案串流操作
透過 FileStream 開啟檔案，展示了如何結合串流物件與播放器來停止音訊。
